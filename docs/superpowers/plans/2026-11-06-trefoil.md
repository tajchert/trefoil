# Trefoil Implementation Plan

> **For agentic workers:** Use subagent-driven development; the user explicitly requested parallel work. Agents own disjoint files in this checkout, overriding the sequential default.

**Goal:** Build a native Android T3 Code client for direct pairing, projects/threads, streaming conversations, send/interrupt, runtime requests and reconnect.
**Architecture:** Kotlin/JVM model and protocol/session modules, Android Keystore storage, Compose app. Use full T3 V2 projections first.
**Tech Stack:** Kotlin, Compose Material 3, coroutines, kotlinx.serialization, OkHttp, Gradle.
**Spec:** ../specs/2026-11-06-trefoil-design.md (approved approach 2026-11-06).

## Global Constraints

- Name Trefoil; package com.tajchert.trefoil; Android first, native iOS later.
- T3 protocol V2; no herdr/SSH conversation semantics.
- Never replay uncertain mutations; disable stale writes; never log credentials.
- Preserve attribution for reused Flocket and T3 code.

## Review Focus

- Pairing URL parsing and cross-origin credential leakage.
- Disconnect while a mutation is in flight.
- Old subscription callbacks after thread or environment changes.
- Snapshot/event ordering and streaming message replacement.
- Unsupported runtime requests and token expiry.
